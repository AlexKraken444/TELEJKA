# TELEJKA для Windows

`public/downloads/TELEJKA-Setup.exe` — лёгкая оболочка сайта для Windows 10/11. Нужен установленный Edge или Chrome. Использует профиль браузера, не хранит пароли отдельно и не меняет настройки уведомлений/автозапуска. Скачивание доступно на регистрации и в профиле.

Установка по кнопке внутри EXE копирует приложение в `%LOCALAPPDATA%\TELEJKA` и создаёт ярлыки TELEJKA на рабочем столе и в меню «Пуск». Права администратора не нужны. Для ручного удаления удалите эти два ярлыка и папку `%LOCALAPPDATA%\TELEJKA`; браузерные данные и аккаунт останутся.

Сборка из корня проекта: `powershell -NoProfile -File desktop/build.ps1`. Требуется Windows с компилятором .NET Framework 4 и установленные npm-зависимости проекта. Иконка собирается из логотипа. EXE не подписан сертификатом издателя: Windows может показать предупреждение неизвестного издателя. Сборка не обходит проверки Windows.

Проверка без установки и открытия окна: `TELEJKA-Setup.exe --check` (код 0: поддерживаемый браузер найден; 2: не найден). Внешние URL и аргументы пользователя не передаются в команду браузера; адрес TELEJKA фиксирован.
